# Game Hub

Cyber Gaming themed, Thai-first responsive frontend for GitHub Pages.

## Deploy
This repository includes `.github/workflows/pages.yml`. In GitHub, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. The workflow deploys automatically on every push to `main`. The published URL will be shown in the workflow's deployment environment.

## Included
- Responsive player-first landing page
- Game library with search and category filters
- Local demo display name and project drafts (browser localStorage)
- Cyber Gaming visual theme

## Important limitations
This is a static frontend prototype, not a production multiplayer platform. Login is not real authentication. Project drafts are stored only in the current browser. Game cards are sample catalogue entries and are not playable games. Cloud saves, database, creator collaboration, file locking/editor, admin moderation, chat, voice, parties, and tournament operations require a secure backend and are not implemented here.

## Local preview
Open `index.html` in a browser or serve this folder with any static web server.
